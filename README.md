# PD Warriors 2027 Digital QR Stubs

Offline-first digital event pass and claiming system for Parkinson’s Disease Warriors Philippines — Get Together 2027.

## Rules
- Patient / PD Warrior: Snack + Lunch + Raffle
- Companion: Snack + Lunch only
- One person = one unique digital QR
- No printed stubs
- One benefit = one claim only
- Offline-first using browser local storage + service worker cache
- Responsive for mobile, tablet, and desktop
